# Числовая угадайка на Go

Простая консольная игра, написанная на языке Go. Программа загадывает случайное число от 0 до 99, а пользователь должен его угадать.

## Особенности
- Используется новый пакет генерации случайных чисел `math/rand/v2`.
- Реализована безопасная обработка некорректного ввода (если пользователь введет буквы вместо числа, программа не упадет).
- Ведется подсчет количества попыток.

## Как запустить
```bash
go run main.go
```
